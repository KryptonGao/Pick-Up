# Phase 1 跨 App 兼容性验证

## 验证目标

在真实 macOS 14 设备上，对每个目标 App 分别验证以下三条路径：

1. 辅助功能 `kAXSelectedTextAttribute` 直接取词。
2. 有辅助功能权限时的自动 `Command-C` 备用流程与剪贴板恢复。
3. 无辅助功能权限时的手动复制和“从剪贴板新建”。

扫描 PDF、图片文字与 OCR 不属于 Phase 1。

## 每项验收步骤

- 在目标 App 中选择一段含中文、英文和 emoji 的文本。
- 记录从按下快捷键到预览出现的时间；正常路径应不超过 3 秒。
- 对照预览确认文字完整、来源 App 正确，且窗口标题在系统可提供时正确。
- AX 直读失败时确认自动复制继续完成流程，并检查复制前的多个剪贴板 item/type 已恢复。
- 撤销辅助功能权限，确认应用不模拟按键，而是给出手动复制步骤。
- 确认失败、取消或返回不会删除已有阅读进度和重点。

## 发布前检查

- 在 macOS 14.x 与当前 macOS SDK 各执行一次完整矩阵。
- 验证 VoiceOver、增加对比度、减少动态效果和减少透明度。
- 使用 Developer ID Application 证书归档 Universal 2，并完成公证与 Gatekeeper 验证。
- 检查签名 entitlements：Hardened Runtime 开启，App Sandbox 关闭。
- 确认运行期间没有网络请求、屏幕录制或持续全局键盘监听。
